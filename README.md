# vintage-mp3-player
It is a vintage mp3 player using Arduino...It has a display to show the song, push buttons to change the song/shuffle/replay, a rotatory wheel to increase or decrease the volume

Why I am making this:
Mainly I am making this for the cool factor and also to get more into electronics

What it does:
Its got a 1.8" TFT LCD (SPI) to display the song you're listening to
It has buttons to change the song/shuffle/replay
A rotatory wheel to increase or decrease the volume

Materials reqired:
🔹 Core
Arduino Nano
DFPlayer Mini
Micro SD Card
🔹 Display
1.8" TFT LCD (SPI)
🔹 Audio
3.5mm headphone jack
Wired earphones
🔹 Power (Rechargeable)
3.7V Li-ion / Li-Po battery
TP4056 charging module (with protection)
Slide power switch
MT3608 boost converter (to 5V)
🔹 Controls
Push buttons (Play / Next / Previous)
rotary encoder (volume)
